# Дневник — школьное расписание и домашние задания

Мобильное приложение-планер в духе Telegram: **день недели = папка, урок = чат,
домашнее задание = сообщение**. Полностью офлайн, все данные — в localStorage
устройства.

## Возможности

- Вкладки дней `Все | Сегодня • Пн | Вт | …` (порядок начинается с сегодняшнего дня)
- Список уроков как список чатов: аватарка, превью последнего задания, **время урока
  справа**, статусы `✓` (не выполнено) / `✓✓` (выполнено) / «Заданий пока нет»
- Экран урока: шапка `← ⊕ Название ⋮`, задания-сообщения с **разделителями дат**
  («3 сентября 2026»), inline-кнопка «Выполнил» → «Сделано ✓✓»
- Добавление задания **только через ⊕**: шторка с настоящим календарём
  (любая дата года, чипы «Сегодня/Завтра») и текстовым полем
- Календарь года: точки на днях с заданиями, задания всех предметов за день
- Поиск по предметам и тексту заданий (с подсветкой и переходом к сообщению)
- Полное редактирование расписания в настройках: добавление, переименование,
  смена иконки/цвета/дня/времени (колесный time picker), удаление с подтверждением.
  Задания привязаны к уроку и **не теряются** при переносе урока на другой день
- Светлая и тёмная темы, демо-данные только при первом запуске

## Структура

```
src/
  App.tsx                  — оболочка, статус-бар, стек экранов
  nav.tsx                  — стек навигации с анимацией
  types/index.ts           — доменные типы
  data/seed.ts             — палитры, иконки, демо-данные
  storage/store.tsx        — контекст + localStorage (уроки, задания, тема)
  utils/date.ts            — русские даты, сетка месяца, плюрализация
  components/              — Avatar, DayTabs, ChatList, CalendarPicker,
                             TimePicker, Sheet/Confirm/Toast (ui), шторки
  screens/                 — MainScreen, ChatScreen, SettingsScreen, CalendarScreen
```

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # прод-сборка в dist/
```

## Android

Приложение — mobile-first PWA: откройте его в Chrome на телефоне и выберите
«Добавить на главный экран» — оно установится как приложение (иконка, полноэкранный
режим, офлайн-хранение данных). Для нативной обёртки APK проект совместим с
Capacitor/Bubblewrap поверх собранного `dist/`.
